# Зачёт

Учебная платформа с кабинетом преподавателя, списками студентов, импортом вопросов и таблиц из Word, тестированием, таймером, оценками и пересдачами.

**Этот репозиторий содержит полноценный сайт с Python-сервером. GitHub хранит исходный код; GitHub Pages не запускает Python и базу данных.** Для полноценного сайта разместите проект на компьютере в учебной сети или сервере с Python. Публикация репозитория сама по себе не запускает сайт.

## Файлы

| Файл / папка | Назначение |
| --- | --- |
| `index.html` | HTML-страница с подключением скрипта и стилей |
| `script.js` | Готовый JavaScript-интерфейс, включая React |
| `style.css` | Оформление сайта |
| `img/` | Статические изображения и значки |
| `zachet_server.py` | Python API, учётные записи, тесты, SQLite и mDNS |
| `requirements.txt` | Библиотеки Python |
| `.gitignore` | Исключение рабочих данных и локальных настроек |
| `.github/workflows/check.yml` | Автоматическая проверка Python, JavaScript и файлов интерфейса |

JavaScript и CSS уже собраны: устанавливать Node.js для запуска сайта не требуется. `script.js` содержит готовую сборку существующего интерфейса. Для изменения React-компонентов используйте исходники из полного проекта `zachet_python_project.zip`, выданного ранее.

## Загрузить на GitHub

1. Распакуйте скачанный архив.
2. Создайте на GitHub новый репозиторий, например `zachet`.
3. Выберите **Add file → Upload files**.
4. Загрузите **содержимое** папки `zachet-github`, чтобы `index.html`, `README.md` и `zachet_server.py` лежали в корне репозитория. ZIP загружать вместо файлов не нужно.
5. Сохраните изменения кнопкой **Commit changes**.

Для добавления скрытых файлов `.gitignore`, `.gitattributes`, `.python-version` и папки `.github` удобнее использовать Git. В терминале внутри распакованной папки выполните:

```bash
git init
git add .
git commit -m "Добавлен сайт Зачёт"
git branch -M main
```

Затем выполните команды `git remote add origin ...` и `git push -u origin main`, которые GitHub покажет для вашего нового пустого репозитория. Не используйте чужой адрес репозитория вместо своего.

## Запуск сайта

Нужен Python 3.12 или новее. Откройте терминал в корне проекта:

```bash
python -m pip install -r requirements.txt
python zachet_server.py
```

При первом запуске задайте почту и пароль преподавателя в консоли. Рабочие данные автоматически сохраняются в `zachet_data/`; эта папка не должна попадать в репозиторий.

По умолчанию сервер работает в 16 потоках и объявляет адрес `http://test.local` через mDNS. Кабинет преподавателя: `http://test.local/teacher`. Нужна одна доступная локальная сеть с поддержкой mDNS на устройствах.

Если порт 80 занят или недоступен:

```bash
python zachet_server.py --port 8080
```

Адрес: `http://test.local:8080`. Если mDNS в вашей сети недоступен:

```bash
python zachet_server.py --no-mdns --port 8080
```

Сервер выведет адрес по IP. Для нескольких сетевых интерфейсов: `--mdns-ip 192.168.1.25` (подставьте адрес своего компьютера).

Для внешнего Python-хостинга используйте фактический порт и HTTPS-адрес сервера:

```bash
python zachet_server.py --no-mdns --host 0.0.0.0 --port 8000 --public-url https://your-school.example
```

Замените пример адреса своим доменом. Потребуются настройка самого хостинга и сохранение `zachet_data` на постоянном диске. Владелец первоначально создаётся через консоль Python-сервера. Для облачного запуска без интерактивной консоли сначала настройте владельца в поддерживаемой консоли сервера командой `python zachet_server.py --init-owner --no-mdns`.

## GitHub Pages

GitHub Pages поддерживает статические HTML/CSS/JS, но не исполняет Python. Этот интерфейс обращается к `/api/` на Python-сервере: размещение этих трёх файлов на Pages не обеспечит вход, импорт Word, таймеры и запись оценок. Не используйте `python -m http.server` как замену API: он лишь раздаёт файлы.

Для полной работы размещайте интерфейс и Python API на одном домене, используя включённый сервер. Автоматическое развёртывание на Pages намеренно не настроено, чтобы не выдавать неработающий интерфейс за полноценный сайт.

Документация GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Данные и редактирование

Внешние `index.html`, `script.js`, `style.css` и `img/` используются сервером при наличии рядом с `zachet_server.py`. Отредактируйте файл и обновите страницу. Рабочая база, исходные Word-документы, фотографии из импортов и ключ почты хранятся в `zachet_data`, вне публичных файлов.

Копируйте рабочую папку целиком для резервного копирования после остановки сервера. Новая установка создаёт чистую базу; облачные списки, банки и результаты автоматически не переносятся. Готовых паролей и реальной базы студентов в этом репозитории нет.
